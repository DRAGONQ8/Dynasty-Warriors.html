# RIFTBANNER 2.0 — رايات الصدع

لعبة قتال ثلاثية الأبعاد عربية في المتصفح، بأبطال وعالم ورسوم إجرائية وصوت أصلي. إصدار **عهد الرايات** يوسّع الحملة إلى ٨ ساحات ويضيف ٦ أبطال ليصبح العدد ١٢، مع تطوير المراحل الثلاث السابقة.

## اللعب

افتح [index.html](index.html) في Chrome أو Edge أو Samsung Internet حديث مع تسريع الرسوم. الملف يتضمن محرك Babylon.js وكل محتوى اللعبة، ويعمل دون اتصال بالإنترنت ولا يحتاج إلى تثبيت. على الهاتف يُفضّل اللعب بالوضع الأفقي. يمكن أيضًا استضافة الملف مباشرة على GitHub Pages.

التقدم يُحفظ في المتصفح الذي تلعب فيه. استورد أو صدّر ملف JSON من **الإعدادات ← التقدم** لنقل حفظك أو الاحتفاظ بنسخة. حفظ الإصدارات السابقة، بما فيها سجلات ٤ أو ٦ أبطال، متوافق؛ تبقى الخبرة والترقيات والنتائج وربط الأزرار. تخزين الملفات المحلية قد يختلف بين المتصفحات؛ الاستضافة عبر HTTPS مناسبة لحفظ أكثر استقرارًا.

## ما الجديد؟

- **١٢ بطلًا:** كارث، سيرا، نيفارا، تورفيك، دايرون، ميليس، فالين، ليس، ساهر، برينيا، أورييل، ريفن. لكل بطل سلاح ودور وميزة ومهارتان وضربة قصوى؛ يفتح تقدم الحملة الأبطال الإضافيين.
- **حملة من ٨ ساحات:** أهداف أسر الرايات وهزيمة الضباط وحماية القائد والمرافقة. خمس ساحات جديدة ببيئات ساحلية ومستنقعية وصحراوية وجليدية وبركانية، وقادة بأساليب ومراحل قتال مختلفة.
- **آثار وتجهيزات:** خمس مكافآت حملة قابلة للتجهيز وأسلوب القيم الأصلية، مع تجهيز مستقل لكل بطل وزيادات للحياة والضرر وتجدد الطاقة وسرعة استعادة المهارات.
- **قتال أوسع:** ست ضربات عادية ومسارات شحن C1–C6، قفز وهجمات جوية، صدّ وتفادٍ متقن، مكافآت للتتابع، دعم للحلفاء، وثلاثة خيول قابلة للركوب بطاقة للعدو وهجمات من السرج.
- **سجل الحرب:** بحث وتصفية للأبطال والقادة والساحات، دليل قتال و١٠ إنجازات وسجل دائم للانتصارات والإسقاطات والإتقان.
- **واجهة عربية محسّنة:** معاينة ثلاثية الأبعاد للأبطال، خريطة حملة، تعليمات وأهداف وتبريد المهارات، مع تحكم باللمس ولوحة المفاتيح ويد التحكم وإعدادات أداء وصوت قابلة للتعديل.

## التحكم الافتراضي

يمكن إعادة ربط الأزرار من الإعدادات. الكاميرا مستقلة عن حركة البطل؛ اسحب الفأرة أو مساحة الميدان الحرة على شاشة اللمس لتدويرها.

| --- | --- | --- |
| التحرك | W A S D | العصا اليسرى |
| الكاميرا | سحب الفأرة | العصا اليمنى |
| ضرب | J أو زر الفأرة الأيسر | □ |
| شحن | K أو زر الفأرة الأيمن | △ |

## التطوير والتحقق

المصدر في `src/` مقسّم حسب البيانات والحفظ والتحكم والعالم والقتال والأهداف والواجهة والتطبيق. البناء يجمع هذه الأجزاء ويتحقق من صحة JavaScript، ثم يضمّن نسخة Babylon المحلية في `index.html`. عدّل المصدر ثم أعد البناء؛ لا تعدّل الملف الناتج مباشرة.

```bash
npm ci
npm run build
npm test
```

لبناء نسخة إضافية في `dist/riftbanner.html`:

```bash
npm run build:standalone
```

اختبار المتصفح يستخدم Playwright ومتصفح Chromium؛ المسار الافتراضي `/usr/bin/chromium` ويمكن تغييره عبر `CHROMIUM_PATH`. يستخدم الاختبار خادم HTTP محليًا مؤقتًا، ويتحقق من تشغيل HTML المستقل دون شبكة أو تحميل أصول خارجية. يحاول فتح `file://`؛ إذا منعته سياسة نظام Chromium، يعلن ذلك ويختبر محتوى الملف نفسه بوثيقة محلية دون اتصال.

```bash
npm run test:browser
# صور اختيارية للقوائم والمعارك:
ARTIFACT_DIR=test-results npm run test:browser
```

اختبارات Node تتحقق من ترحيل الحفظ والتقدم والتجهيز والإنجازات وآثار القتال والصدّ والتفادي ومراحل القادة. اختبار المتصفح يتحقق من القوائم والبحث والمعاينة والشاشات الصغيرة والتحكم الحقيقي، ويجرب قتال الأبطال الاثني عشر ويحمّل الحملة والمناوشة لكل الساحات ويكمل المراحل الجديدة عبر شروط أهدافها. المحاكاة الآلية لا تحل محل تقييم توازن الصعوبة خلال اللعب البشري.

## English

**RIFTBANNER 2.0: Banner Accord** is an original Arabic browser action game with 12 playable commanders and 8 campaign battlefields. The expansion adds five themed chapters, new officers with phased combat, per-hero relic loadouts, a searchable war codex and 10 achievements. Existing chapters, combat, battlefield detail and menus are improved.

Open `index.html` in a modern WebGL browser. The file embeds Babylon.js and all procedural assets, so gameplay works offline. Keyboard, mouse, touch and gamepad are supported; use landscape orientation on phones. Save progress is local to the browser, with JSON import/export and migration from older four- and six-hero saves.

For development, run `npm ci`, `npm run build` and `npm test`. `npm run test:browser` runs the Playwright smoke suite with system Chromium; override `CHROMIUM_PATH` if needed. `npm run build:standalone` also writes `dist/riftbanner.html`. Optional screenshots use `ARTIFACT_DIR=test-results`.

Babylon.js 9.29.0 is distributed under Apache-2.0; its license and attribution remain embedded in the generated HTML and the vendored source. Game characters, geometry, textures and synthesized audio are original.
